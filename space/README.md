# NCR Description Assistant (web edition)

Checks a nonconformance defect description for an observable condition,
location, and quantity, flags cause speculation, and suggests a defect
category. A single self-contained page: no server, no external scripts, and
nothing typed leaves the browser. All example data is synthetic.

Built by Marcus Faulkner, Quality Inspector.
